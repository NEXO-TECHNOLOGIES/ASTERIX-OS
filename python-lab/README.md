# Python Lab for AI Reasoning and Automation

This lab is designed to improve practical AI reasoning through real-world Python tasks that mirror infrastructure, shell automation, debugging, and API workflows.

## Curriculum goals

- practice root-cause debugging
- learn OS-level automation with Python
- work with API and dashboard logic
- model VM lifecycle workflows
- improve structured problem solving
- build a repeatable progression from beginner to infra-level automation thinking

## Training progression

The lab now follows a simple curriculum model:

- Beginner: debugging, shell basics, request handling, semantic HTML
- Intermediate: VM lifecycle logic, structured data models, CSS responsiveness, UI flow design
- Advanced: infrastructure-oriented thinking, metrics, dashboard design, interface polish, and UX reasoning

The program now includes a dedicated web-dev and UI/UX track so the training does not stop at Python logic alone.

Each challenge has:
- a difficulty level
- a score value
- a skill focus area
- a checkpoint for progress tracking

## How to use it

1. Review the curriculum with `python curriculum.py`.
2. Open a prompt in `prompts/`.
3. Attempt to solve the corresponding script in `exercises/`.
4. Compare your work to the matching solution in `solutions/`.
5. Run the tracker to record progress and total score.
6. Move to the next difficulty level after you complete the checkpoint.

## Suggested daily loop

- 15 min: read the prompt and identify expected behavior
- 15 min: write the minimal failing solution
- 10 min: run it and observe output/errors
- 10 min: trace the root cause and patch small fixes
- 10 min: compare with the solution and explain the difference
