# Front-end + Infrastructure Training Track

This training path is designed to push the AI beyond Python basics into real product work.

## Focus

- semantic HTML
- responsive CSS
- dashboard design
- UI clarity and hierarchy
- controls and operator experience
- product thinking for infrastructure tooling

## Challenge flow

1. Build a clean landing page structure
2. Create a responsive dashboard layout
3. Design a control panel flow for operators
4. Polish a professional dashboard experience
5. Evaluate UX quality using a rubric

## Exercise set

- `mock_dashboard_01.py` — basic admin dashboard layout
- `mock_dashboard_02.py` — responsive dashboard panels
- `ux_audit.py` — rubric-based UX scoring
- `scoring_system.py` — evaluate structure, clarity, and polish

## Suggested learning loop

- design the interface
- identify key user actions
- grade clarity and hierarchy
- improve layout and status communication
- re-score until the interface feels operational and clean
