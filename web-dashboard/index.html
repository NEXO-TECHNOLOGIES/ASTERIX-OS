⚡ How to Flash with Rufus (Windows with Persistence):

  1. Download and open Rufus (rufus.ie).
  2. Select your USB Flash Drive (8 GB or larger).
  3. Select the ASTERIX ISO and set the Persistent partition size slider (4 GB - 16 GB).
  4. Ensure Partition Scheme is MBR and Target is BIOS or UEFI.
  5. Click START and choose "Write in ISO Image mode (Recommended)".
